# محفظتي المالية — Personal Finance Portfolio Tracker

تطبيق ويب شخصي لإدارة ومتابعة محفظتك المالية بالكامل: حسابات بنكية، أسهم، معادن ثمينة، شهادات ادخارية، ديون، زكاة، وتقارير مالية — بدون أي سيرفر، كل البيانات تتخزن في مشروع Supabase خاص بك أنت.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة فقط |
| `style.css` | كل التنسيقات |
| `app.js` | كل منطق التطبيق |
| `schema.sql` | سكريبت إنشاء قاعدة البيانات كاملة على Supabase |

## خطوات التشغيل (لكل مستخدم على حدة)

### 1) أنشئ مشروع Supabase خاص بك
- سجّل مجانًا على [supabase.com](https://supabase.com)
- أنشئ مشروعًا جديدًا (ناحية قريبة منك جغرافيًا أفضل للسرعة)

### 2) شغّل قاعدة البيانات
- من داخل مشروعك: **SQL Editor → New query**
- الصق محتوى `schema.sql` كاملاً واضغط **Run**

### 3) فعّل تسجيل الدخول بالبريد وكلمة المرور
- من القائمة: **Authentication → Providers → Email**
- تأكد إنه مفعّل (مفعّل افتراضيًا عادةً)
- لو عايز تدخل فورًا بعد التسجيل بدون تأكيد بريد إلكتروني: عطّل **Confirm email** من نفس الصفحة (اختياري، مناسب للاستخدام الشخصي)

### 4) هات بيانات الاتصال
- من **Project Settings → API**: انسخ **Project URL** و **anon public key**

### 5) افتح التطبيق
- افتحه مباشرة (`index.html`) أو انشره على **GitHub Pages**
- أول مرة: الصق الـ Project URL والـ anon key في شاشة "الاتصال بقاعدة بياناتك"
- اعمل حساب جديد (Sign up) بإيميلك واسم مستخدم وكلمة مرور
- خلاص — التطبيق جاهز وبياناتك محفوظة بالكامل في مشروعك الشخصي

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة (`index.html`, `style.css`, `app.js`) لـ repo عام أو خاص
2. **Settings → Pages → Source**: اختر الفرع (عادة `main`) والمجلد الجذر
3. هيديك رابط عام زي `https://username.github.io/repo-name/`

> ⚠️ **ملاحظة أمان:** الـ anon key مش سر خطير بحد ذاته (مصمم للاستخدام في المتصفح)، لكن الحماية الحقيقية هي سياسات **Row Level Security** في `schema.sql` اللي بتمنع أي حد مش مسجّل دخول من قراءة أو تعديل بياناتك. متشاركش كلمة المرور بتاعتك مع حد.

## تحديث تلقائي للأسعار
- **أسعار الصرف**: يدويًا من صفحة "تحديث الأسعار"، أو تلقائيًا يوميًا عبر [open.er-api.com](https://open.er-api.com) (مجاني، بدون مفتاح)
- **الذهب والفضة**: أضف مفتاح [GoldAPI.io](https://www.goldapi.io) من صفحة الإعدادات للتحديث التلقائي اليومي (لأنواع المعادن المملوكة فعليًا فقط)
